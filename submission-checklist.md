# Submission Checklist

**Manuscript:** _______________  **Phase:** 1 / 2  **Target venue:** _______________
**Deadline:** _______________  **Paper ID:** _______________

Nothing is submitted until every box is ticked.

## Venue

- [ ] Venue scope genuinely matches the work
- [ ] Proceedings confirmed to be published in IEEE Xplore
- [ ] Venue approved by the Course Professor
- [ ] Call for papers read in full; deadline and time zone recorded
- [ ] Author kit downloaded

## Manuscript

- [ ] Written inside the official IEEE template from the first draft
- [ ] Within the page limit, including references
- [ ] Title states the artifact and the contribution
- [ ] Abstract under 200 words with a headline performance number
- [ ] Index terms / keywords chosen from the venue's list where one exists
- [ ] Contribution stated as explicit claims in the introduction
- [ ] Methodology reproducible from the text alone
- [ ] Every figure and table referenced and interpreted in the text
- [ ] Figures legible in greyscale and at printed size
- [ ] Limitations stated plainly
- [ ] References in IEEE style; every one checked to exist and to be reachable
- [ ] No fabricated, AI-hallucinated, or unread citations

## Integrity

- [ ] Similarity check run; result at or below the institutional threshold
- [ ] No single source exceeds the allowed share
- [ ] AI-use statement present and accurate
- [ ] Authorship agreed in writing; order confirmed by all authors
- [ ] Ethics clearance referenced where human participants are involved
- [ ] Every reported number traceable to raw data in the repository

## Technical

- [ ] PDF version 1.4 or later
- [ ] All fonts embedded or subset
- [ ] No password or security settings
- [ ] No bookmarks, links, crop marks, or timestamps
- [ ] IEEE PDF eXpress account created and conference ID obtained
- [ ] PDF eXpress validation passed; approved file downloaded and used

## After submission

- [ ] Submission confirmation archived
- [ ] Paper ID recorded
- [ ] Screenshot of the submission page saved as proof of submission
- [ ] Copyright form status noted
- [ ] Presenting author identified
