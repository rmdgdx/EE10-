## Standing rules

1. Write the entry the same day. A reconstructed logbook is visible from orbit.
2. Record instrument settings, not just readings.
3. Photograph the bench setup for any measurement that will appear in a paper.
4. Never overwrite a wrong number — strike it through and write the correction
   with the reason.
5. Cross-reference the commit hash so code and observation stay linked.
